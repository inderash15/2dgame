Architecture Limitations & MongoDB Production Upgrade Path

Current Standalone Mode: All games, teams, and allocations persist in browser LocalStorage (~5MB browser quota, easily supporting 1,750+ game records). Because LocalStorage is isolated per browser/device and inspectable by users, multi-device simultaneous access requires a centralized backend.

1. MongoDB Atlas Collections
Migrate games, teams, and allocations (with unique index on gameId) to MongoDB for atomic concurrency safety.
2. REST / GraphQL API Layer
Expose Node.js/Express or FastAPI endpoints with server-side pagination and transactional bulk-allocation writes.
3. JWT & RBAC Auth
Replace client-side demo auth with HTTP-only JWT cookies, bcrypt password hashing, and role-based access control.
